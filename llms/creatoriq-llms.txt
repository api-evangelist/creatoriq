# CreatorIQ

> Enterprise creator- and influencer-marketing platform. Brands and agencies use CreatorIQ to discover
> creators, run a private creator network, manage and measure campaigns, pay creators, and report across
> Instagram, TikTok and YouTube. Its public REST API exposes the customer's own CRM — publishers,
> campaigns, lists, one-sheets, social accounts, forty reporting views, ecommerce and affiliate
> attribution, brand safety, and payouts — plus a pub/sub webhook surface.

Generated by API Evangelist from CreatorIQ's own published documentation and OpenAPI. Not published by
CreatorIQ: probing /llms.txt on creatoriq.com, apidocs.creatoriq.com, apis.creatoriq.com and
app.creatoriq.com returned 404/403 on 2026-08-11.

## Facts an agent needs first

- Base URL: https://apis.creatoriq.com
- Auth: `x-api-key: <key>` header on every request. Issued manually by a CreatorIQ account manager or
  sales contact at partner or division level. No OAuth, no scopes, no self-serve key creation.
- Rate limits: 100,000 requests/day and 5 requests/second per key. `429` on exhaustion. No
  `RateLimit-*` and no `Retry-After` headers are documented — back off blind.
- Idempotency: not supported. No idempotency key exists anywhere in the API.
- Errors: bespoke JSON, not RFC 9457. `403` (not `401`) is what a missing `x-api-key` returns.
  `400` (not `404`) is what an unknown publisher or campaign id returns.
- Pagination: three dialects — `page`/`size` on CRM v1, `Page`/`PageSize` on reporting views, `cursor`
  on Payments and SafeIQ.
- Versioning: URI path. `/crm/v1` and `/crm/v2` coexist; the split was announced 2025-04-16.
- Deprecation: documented one-year window with `Deprecation` and `Sunset` headers (RFC 8594), stated in
  prose but not declared in any spec.
- Schema evolution: CreatorIQ instructs integrators to be tolerant readers — responses gain fields
  without a version bump.

## What CreatorIQ does not publish

No SDKs in any package registry. No public GitHub repositories. No CLI. No MCP server. No A2A agent
card. No AsyncAPI. No `/.well-known` documents of any kind, including security.txt. No llms.txt.
No published pricing — https://www.creatoriq.com/pricing is a request form.
